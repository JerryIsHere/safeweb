## Training and evaluation

Command:

```bash
source .venv/bin/activate
python scripts/train_phishvn_model.py
```

Four models use the same 52 features, fit rows (29,637), and untouched test rows (6,624). Random Forest uses 100 trees, maximum depth 16, minimum leaf size 3, and balanced-subsample weights. Gradient Boosting uses 100 depth-3 trees at learning rate 0.1. SVM uses StandardScaler + LinearSVC with sigmoid calibration. Logistic Regression uses StandardScaler and balanced class weights.

## Browser export and parity

The exported `web/static/model-data.js` includes all four inference representations, public suffix rules, and PhishVN lookup signatures. `web/static/database-records.json` contains the client-side explorer records and source metadata. They are generated by:

```bash
python scripts/export_browser_model.py
python scripts/compare_browser_model.py
```

The parity checker passed on 10 valid and 6 invalid inputs. Maximum feature delta was `1.33e-15`; maximum probability delta was `3.33e-16`.

## Application behavior

- URL normalization adds `https://` when the scheme is absent, adds `.com` for a bare word, strips default ports, lowercases scheme/host, and removes trailing path slashes.
- The local-only path performs PhishVN matching and four-model inference without network access.
- Live DNS, embedded redirect analysis, metadata, and screenshots require an explicit opt-in; URL data is shared with Google DNS and Microlink/WordPress preview services only then.
- Direct HTTP redirect inspection can be blocked by browser CORS. HTTPS display reports the URL scheme and does not validate TLS certificates.
- The interface has Vietnamese/English translations, three contrast modes, qualitative risk tiers, inspection criteria, and live-result states.
